3. [`visual-directions.html`](visual-directions.html) — interactive same-state comparison for Overview, File Library, Quick Preview and Settings.

## How to compare

Open `visual-directions.html` in a browser and keep the same screen selected while switching:

- **A · Quiet Native**
- **B · Zen Mist**
- **C · Focus Canvas**

Then repeat for all four representative screens.

The prototype deliberately uses the same content and the same W6-05-derived product states in every direction. Differences therefore come from visual language, density, material hierarchy and spatial composition rather than from changing the product story between concepts.

## Current recommendation

`02-VISUAL-DIRECTIONS.md` recommends **B · Zen Mist** as the strongest default candidate, with A as the restraint benchmark and C as the ambition benchmark.

This is not the final W6-06 selection. Product-owner review is required before final tokens, shell/state specifications and W6-07/W6-08 handoffs are frozen.
